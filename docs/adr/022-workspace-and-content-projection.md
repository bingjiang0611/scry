# 022: Project observed state without granting authority or copying payloads

**Status:** Accepted (documents existing behavior)

Repository and terminal grouping keys are not permission. A structural workspace request still needs host-side Git checks, canonical path validation and project authority. Accept only full local or already-fetched remote-tracking refs, recheck the selected ref's HEAD at preparation, and use a locally available origin/main as the preferred default. Ref search is capped; refine a capped query rather than assuming absence. Compute workspace diff totals and patches from the same immutable trees. Multiple push destinations are not writable through this contract; hide credentials in the displayed destination. GitHub identity is not transport auth. Keep operation results tied to authoritative receipts, and recheck PR status at dispatch rather than treating partial checks as passing.

Worktree progress is evidence, not an estimate: publish metadata readiness only after preparation succeeds and checkout progress only from Git or completed checkout. Cancellation ends before Provider launch; details are bounded and sanitized. The same contract crosses the desktop transport.

The paired device receives a bounded, read-only projection of the same panels as the Mac, not remote execution or a scan request. Keep unknown values null with reasons; missing live state is not disconnection. Rank model rows with known costs before capping, keep estimation markers, and preserve coverage counters. Project findings without evidence paths, key names or hashes. A static scan that did not run is not a clean result.

A content reference names a scoped body, not permission to read an arbitrary path. Preserve the schema-v1 compatibility name; absence can mean an older producer, not full capture. Full bodies are separate from bounded previews; check redaction provenance. Manifest descriptors carry the root and totals without materializing the tree; main validates contents, counts and byte bounds. Stored Provider evidence is verbatim: credential masking is for display, not evidence sinks. A local session title is a catalog label, not transcript content.

Terminal replay offsets are bytes in the UTF-16LE recording. In daemon mode the App reads a bounded output queue by cursor; a restarted stream begins at the retained output. Each call names its workspace again, and the daemon refuses unknown directories. Resolve handlers against the current terminal runtime after reclamation. The App normally shuts down its terminals on quit. After a crash, idle reclamation starts only when the last parked event poll ends. Bound the poll wait plus idle threshold plus check cadence to 90 seconds, as asserted by [the reclamation test](../../src/daemon/terminal-service-reclaim.test.ts). Do not leak other workspace identities when metadata reads fail. After renderer reload, surface the last observed restart reason once so an interrupted view is not mistaken for continuous execution.

A daemon-local recorder content read still checks the App-supplied workspace against daemon authority. The empty workspace sentinel is reserved for unscoped App trace bodies; missing and invalid claims are refused. The App rechecks its window selection when the response returns. The shared session lifecycle receives the confirmed count before bulk archived deletion and sends actual progress back through the App event feed. A mismatched count or deletion fingerprint must leave the data intact. An unsent draft has no Provider binding to fence. Query fixtures distinguish a missing workspace claim from an existing directory outside daemon authority, and an unsupported Provider facet from an empty result. Workbench writes must refuse a stale revision rather than overwrite newer content. Terminal tests exercise a stale ownership epoch, cursor reads without duplicate output, and idle reclamation with a controlled short timeout rather than a real App crash.

Known-project reads consult the daemon's current authority, including session directories, rather than a cached App list. Looking up a directory does not persist it. The App's catalog readers must observe daemon writes; the daemon validates picker results and Pi profile probe directories. A failed profile handshake is reported without storing the profile.

Keep a grouped session's execution directory distinct from its project root. Conversation grouping does not rewrite the raw native catalog. Fetch history newest first in small pages: each archived turn adds a file read and parse. Wait for completed runs to publish before reading archival evidence. Pi archives are not profile-scoped; keep the profile in other Providers' archive lookups. A matching catalog path may identify historical storage, but it grants no authority to use that directory as a workspace. Measure archive reading separately from per-turn content persistence.

Older-page reads must not switch the session or replay its side effects. Reject a stale revision or another session's cache key with no page. The daemon reports selection with the first page; the App applies it. Reuse normalized events, hydrate attachments and annotate Hook commands only for the page crossing IPC. Suppress superseded cumulative snapshots only in that projection; keep the archive and cache complete. [#172](https://github.com/bingjiang0611/scry/issues/172) tracks bounding cold transcript work before the first page. Retrieve one turn's terminal evidence separately when the usage and cost summary needs it.

For renderer pagination, prepend only a nonempty page from the same window with the same total and an exactly adjacent offset. Use the original session ordinal for synthesized run IDs so pages cannot collide. Distinguish reaching the beginning by paging from an initial already-complete window. Preserve the references of existing turns when only an older page is added.

In the renderer, prefetch older history before the top boundary. A short viewport may not scroll, so fill it proactively, but do not automatically repeat a fill if the turn count did not change. Use explicit scroll compensation rather than combining it with browser anchoring. Benchmarks identify the autoload mode via a stable attribute, not a hint that disappears when history is exhausted.

A renderer cache holds only bounded recent history for display. It cannot authorize resume, own a subscription, or replace the main read; show cached data as such until that read settles. Use exact wire equality to preserve render identities and measure the budget in estimated UTF-16 bytes, not heap size. Persisted window selection is only a reload hint: revalidate it on restore, do not persist an unselectable legacy session, and do not let a completed run overwrite a different selection. Remember a newly created session when its turn completes while it still owns the view. Storage failure does not block selection.

Switch the visible session immediately without showing the previous session’s turns under the new selection. Sidebar activity cannot rule out a live run, and failed live adoption does not rule out saved history. Confirm cached history in place only if the authoritative read agrees and no focus, start, or clear superseded it. Otherwise commit the replacement turns and their evidence status together. Restore an unsent draft without sending it; command and skill refresh must not block reset. Respect focus moved since the user’s original click.

Only catalog metadata (pin, archive, and title) updates the sidebar optimistically; transcript, Git, and delete operations do not. Roll back against the same workspace, Provider, profile, and session key; a row that no longer exists is not recreated by a stale patch. Keep the rename input until the write succeeds. Drop queued prompts before archiving so a run that finishes during the write cannot drain another prompt into that session. Some Providers only supply the native session ID at completion: move drafts and queued follow-ups from the run’s original owner even if the user already switched sessions. Restore model settings from Scry’s recorded request rather than observed usage or current global defaults; an explicit choice for that session wins.

An invalid saved workspace selection blocks a new start but keeps the composer text; it must not silently select the current directory. Consume only the acknowledged operation and submitted draft content, preserving newer edits and leaving an occupied destination draft alone. Resolve a workspace start to its exact run’s catalog alias, not the latest session in that directory. If the start reply is lost, recover from the recorded operation and matching command receipt rather than sending the write again.
