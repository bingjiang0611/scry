# 022: Project observed state without granting authority or copying payloads

**Status:** Accepted (documents existing behavior)

Repository and terminal grouping keys are not permission. A structural workspace request still needs host-side Git checks, canonical path validation and project authority. Accept only full local or already-fetched remote-tracking refs, recheck the selected ref's HEAD at preparation, and use a locally available origin/main as the preferred default. Ref search is capped; refine a capped query rather than assuming absence. Compute workspace diff totals and patches from the same immutable trees. Multiple push destinations are not writable through this contract; hide credentials in the displayed destination. GitHub identity is not transport auth. Keep operation results tied to authoritative receipts, and recheck PR status at dispatch rather than treating partial checks as passing.

Worktree progress is evidence, not an estimate: publish metadata readiness only after preparation succeeds and checkout progress only from Git or completed checkout. Cancellation ends before Provider launch; details are bounded and sanitized. The same contract crosses the desktop transport.

The paired device receives a bounded, read-only projection of the same panels as the Mac, not remote execution or a scan request. Keep unknown values null with reasons; missing live state is not disconnection. Rank model rows with known costs before capping, keep estimation markers, and preserve coverage counters. Project findings without evidence paths, key names or hashes. A static scan that did not run is not a clean result.

A content reference names a scoped body, not permission to read an arbitrary path. Preserve the schema-v1 compatibility name; absence can mean an older producer, not full capture. Full bodies are separate from bounded previews; check redaction provenance. Manifest descriptors carry the root and totals without materializing the tree; main validates contents, counts and byte bounds. Stored Provider evidence is verbatim: credential masking is for display, not evidence sinks. A local session title is a catalog label, not transcript content.

Terminal replay offsets are bytes in the UTF-16LE recording. In daemon mode the App reads a bounded output queue by cursor; a restarted stream begins at the retained output. Each call names its workspace again, and the daemon refuses unknown directories. Resolve handlers against the current terminal runtime after reclamation. The App normally shuts down its terminals on quit. After a crash, idle reclamation starts only when the last parked event poll ends. Bound the poll wait plus idle threshold plus check cadence to 90 seconds, as asserted by [the reclamation test](../../src/daemon/terminal-service-reclaim.test.ts). Do not leak other workspace identities when metadata reads fail. After renderer reload, surface the last observed restart reason once so an interrupted view is not mistaken for continuous execution.

A daemon-local recorder content read still checks the App-supplied workspace against daemon authority. The empty workspace sentinel is reserved for unscoped App trace bodies; missing and invalid claims are refused. The App rechecks its window selection when the response returns. The shared session lifecycle receives the confirmed count before bulk archived deletion and sends actual progress back through the App event feed. A mismatched count or deletion fingerprint must leave the data intact. An unsent draft has no Provider binding to fence. Query fixtures distinguish a missing workspace claim from an existing directory outside daemon authority, and an unsupported Provider facet from an empty result. Workbench writes must refuse a stale revision rather than overwrite newer content. Terminal tests exercise a stale ownership epoch, cursor reads without duplicate output, and idle reclamation with a controlled short timeout rather than a real App crash.

Known-project reads consult the daemon's current authority, including session directories, rather than a cached App list. Looking up a directory does not persist it. The App's catalog readers must observe daemon writes; the daemon validates picker results and Pi profile probe directories. A failed profile handshake is reported without storing the profile.

Keep a grouped session's execution directory distinct from its project root. Conversation grouping does not rewrite the raw native catalog. Fetch history one IPC page at a time, newest first; retrieve one turn's terminal evidence separately when the usage and cost summary needs it.
