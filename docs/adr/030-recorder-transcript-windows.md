# 030: Reuse transcript reads without reusing unproven evidence

**Status:** Accepted (documents existing behavior)

A transcript window is selected by Provider-native identity, not prompt text, approximate byte offsets, or timestamps alone. A stored capture-stop offset bounds the window so the next prompt cannot enter it. Anchored reads keep the whole selected window instead of moving its start to satisfy a byte cap. Retain a clock-bounded window only for an authorized degraded close; label an unmatched identity partial. A parser-filled timestamp does not prove when work began. Background task launch needs a structured receipt, and progress is not completion.

Cache by the requested projection and current file identity, before finding its anchor. A cached anchor is a candidate: revalidate its line, require the same file without truncation, and look for newer matches in appended bytes. Revisit an unfinished tail and a complete EOF line without a newline. Do not use the single-line shortcut for Codex's stateful scan. Reject or retry a snapshot if the path rotated or truncated during reading. Do not cache a cross-file projection using only the root's identity. Treat a NUL-filled prefix as outside the valid JSONL range. Keep retries for transient I/O bounded, propagate permanent errors, and do not report denied reads as successful evidence.

For Codex, keep the cumulative usage immediately before the window, then prefer the turn's cumulative delta over deduplicated increment frames. Reset increment dedupe at turn boundaries. Bind context and model attribution only to observed evidence; conflicting models remain unattributed. Attach compaction rows to the owning half-open turn window, combining nearby rows for one compaction without reordering equal-time events. Prefer canonical human input over legacy notifications without pairing by text or time. Code-valued tool arguments are evidence, not executable input: use only the supported static forms and preserve opaque calls without inventing nested operations.

For Pi, follow the native before/after ancestry, keeping native extension-authored starts and compaction without inventing a user prompt. For Qoder, accept only child logs authorized by the current turn; verify native identity and scope and avoid symlink traversal. Bound child count, depth and total reads; preserve complete in-budget rows as partial evidence rather than losing a whole oversized child. Child bodies retain their own scope; root usage is authoritative. Discover Codex siblings only in the native date layout. Missing or legacy layout is partial, not an invented match or a fatal recorder failure.
