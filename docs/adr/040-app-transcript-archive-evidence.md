# 040: Keep App archive bodies authoritative when indexing or paging history

**Status:** Accepted (documents existing behavior)

Canonical turn files hold the evidence. The catalog and index are rebuildable projections, not proof of absence. A scoped catalog answers only within its Provider coverage. Bound discovery by total bytes as well as file count and per-file size. Incomplete scans must not publish a complete catalog. Mark writes and deletions dirty rather than rewriting the global catalog on the hot path. A write can land in a directory already enumerated by discovery; check the generation around publication and remove the new index if that race would leave stale metadata trusted.

Per-turn metadata can establish ordering and coverage without loading bodies. Reconcile the index against canonical membership and file stamps; a degraded index cannot rule out recovered turns. Reuse bodies already read by a canonical rebuild rather than reading the selected page again. An unchanged archive stamp must not change just because a sidecar was published. Keep ordinal paging on the total observed at the first page. Legacy monolithic files have different read costs and are not described by segmented metadata. Never fall back to an older copy of a corrupt canonical turn. Explicit profile selection requires corresponding proof; unknown legacy provenance is not proof of the default profile.

Capture opens files within the controlled archive root and rechecks their identity; filenames, metadata and same-size bodies alone are not proof that nothing changed. Inventory can report how ordering would be recovered without reading bodies. If a capture has to recover ordering by streaming the bodies, project only visible text and steer evidence, not large opaque payloads, and verify the digest again on re-read. A recorded conversation turn can instead be verified against its binding profile and recorded item hashes. Mirror writes can fall back from incremental append to atomic replacement; validating capture settings does not suppress full-mode raw mirrors or alter historical copies.

Keep canonical diff patches available through content references. Only the latest cumulative session snapshot needs to cross IPC, including an empty or failed latest snapshot; the cache and archive retain the others. Reuse already parsed page turns only when they came from an unfiltered archive page, and read missing turns separately. Do not deduplicate continuation results solely by run ID or infer a successful result from a settled run. Hydrate attachments after selecting the page. Deletion affects Scry-owned copies, never Provider-native transcripts used for history and resume.

Test a body failure with otherwise valid sidecar stamps; a metadata-only check must not pass it. Cover archive replacement under an unchanged filename, partial discovery under a byte budget, and a write during catalog publication. The bounded capture regression performs a real read per turn, so its test timeout accommodates disk contention without reducing assertions.
