# 038: Keep orchestration decisions, recovery and delivery evidence separate

**Status:** Accepted (documents existing behavior)

The decision function reads a view and produces events, effects and a receipt without I/O. Recheck grant, canonical working directory, workspace authority and trust before dispatch. An immediate dispatch may commit admission and dispatch together after this recheck. Binding and progress cannot precede dispatch. Retryable rejections do not reserve a command ID. Reserved agent behavior is not emitted in this generation. Unknown optional fields are forward compatible; unknown event kinds require a snapshot reset. Missing outcome or actor evidence is unavailable, not exact or attributed to the system. A nullable output sequence distinguishes missing evidence from a number; migration preserves existing nonzero sequences.

Reconcile stale effects, open runs and interactions before clients connect, in one storage transaction. A claim without dispatch is voided. For a dispatched run, prefer committed trace archive evidence, then committed result spans; neither a partial archive nor silence proves terminal completion. Match the conversation and event ledgers: without a `turn.began` event settle a pending turn as not sent, write back a proven terminal conclusion, and flag native session binding conflicts without inventing a native ID.

During the retired shadow rollout (see [ADR 037](037-orchestration-legacy-handoff.md)), shadow mode observed legacy and conversation transitions without changing the user-visible run. Count only accepted commits in commit statistics, and report ordinal mismatches, rejections, missing bodies and failures separately. Pause the import cursor while historical backfill catches up with live events. A shadow body can be staged in memory because shadow mode never dispatches it; queue only after acceptance and do not recreate bodies removed by session deletion. Late historical import must not replace the last outcome of a newer live run.

Build each subscription snapshot at one event-log position. Always include all live runs; only recent terminal history is capped. Durable events come from the event sink. Output and registration hints don't need a pre-first-token SQLite commit. Coalesce output hints per run, not host-admin notices. Forward host-admin payloads intact; omit legacy window notices for run lifecycle transitions that already arrive as durable events. Route structured progress to live metadata and, where applicable, durable evidence; opaque progress does not establish orchestration state. Initial connections and App restarts receive current state rather than previously missed volatile notices. Test both edges of output coalescing and insert a new session between catalog pages to probe pagination.

In daemon regressions, hold the Provider gate across the pending deadline and check that expiry releases the session slot; release the gate before the deadline and check that work resumes without another submit. After restart, the recheck must use persisted ownership, not an empty in-memory cache. Only committed recorder evidence can change an interrupted run's outcome. Commit turn delivery before persisting the conversation file; reconcile a truly absent turn separately from an older turn awaiting deferred import. A terminal result without native binding does not authorize inventing a session ID. The legacy device view may map interruption to cancellation; the authoritative log retains the interruption reason.

The daemon applies the shared MCP trust policy, including the Provider-specific selection of checks. Cache fingerprints by Provider and canonical workspace, including applicable settings. Reuse a fingerprint only while config and executable stamps still match, and include the shell PATH dependency for bare command names. Check both links and resolved targets to detect target edits and retargeting. Reverify after preparation and fail closed if the fingerprint changed or verification fails. Regression tests use an isolated HOME and verify that a denied run was not dispatched.
