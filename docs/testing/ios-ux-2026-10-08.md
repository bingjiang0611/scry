## 首轮失败与外部限制

- 手机先断开，WDA test runner 连接失效；用户重连并重新信任开发证书后继续。
- 机器高负载时 Simulator 创建/列举超时；负载恢复后确认未创建，再建立本次隔离设备。收尾读到 load average 543，补充相机预览 frame 修复后的构建在资源编译阶段超过 200 秒；检查并收敛本次残留构建进程、关闭本次隔离模拟器后再构建。未杀其他用户进程。
- 手机 WDA 第二次连接中断；停止重复恢复，最终安装和普通启动仍通过 CoreDevice 成功。
- Simulator WDA 报 `DTServiceHubClient failed to bless service hub`；停止该自有测试进程，改用可用的原生 AX 检查，不重启全局模拟器服务。
- 早期 `devicectl -selfTest` 参数缺少 `--` 被拒，之后正确分隔 App argv；无操作副作用。
- 最后相机 frame 补丁的真机构建先在资源编译超时（`build-camera-final.log`），核查/收敛后重试又因 Xcode 找不到物理 destination 退出 70（`build-camera-retry.log`）。改用 generic iOS 只验证编译，仍停在 actool 数分钟，已停止本次构建和自有模拟器，没有取消其他工作。后续 Simulator/Release 构建未执行。
- 最后补丁单文件 `xcrun swiftc -swift-version 5 -typecheck -target arm64-apple-ios17.0 -sdk <iphoneos-sdk> apps/ios/ScryRemote/QRScanner.swift` **退出 0**（`camera-typecheck.log`）。这不能替代最终 App 打包、首次允许相机的运行验证或安装回执。

## 尚未验收 / 已知能力边界

- **未执行真实 Provider 发送、真实审批回答、多轮续聊或弱网故障注入**；没有授权费用，也没有为了补报告去执行真实 Agent。
- 最终提交源码尚有上述 2 行相机补丁未重新打包安装，完整真机录屏也未完成。用户要求的“优化后录屏确认没问题”仍不能视为全链路完成。
- 手机端没有一般 Stop 协议；未新增伪停止。当前单未收敛运行、未决 intent 保护是有意限制。现有 transport/host error 都按提交 unknown 保留原 intent；永久拒绝后的放弃/编辑闭环未验收，不能把“重试核对”当作对所有错误都能恢复的保证。
- 草稿仅本次 App 生命周期内保留；未增加落盘附件或跨进程草稿恢复。
- 不覆盖 VoiceOver 全链路、Dynamic Type 全档位、所有 iPhone 尺寸及长时间流式帧时。
