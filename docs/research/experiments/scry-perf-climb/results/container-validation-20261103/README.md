# 容器内的工具验证（2026-11-03）

2 核 Linux 容器、合成的多仓库工作区（根仓库 + 12 个子仓库）、scry 0.2.52、uploader 0.2.7 公开快照、`--rounds 5`、`--pairs 2`。只用来证明判定工具可靠，数值不代表任何真实机器。

- `aa-recorder-hookwrap.md`：两边用完全相同的二进制（A/A）。结论 NO CLEAR CHANGE：0 项变好、0 项变差，68 个计数全部相同，记录摘要相同。（同一批数据在加入原始样本检验之前，按旧的“两次运行极差”规则误判了 24 项，这是改为样本检验 + 运行一致性的原因。）
- `sensitivity-injected-slowdown.md`：候选是故意改慢的测试构建（轮次开始多 150 ms、轮次结束多一次 git 调用）。结论 REGRESSION：8 个场景的轮次开始耗时全部判为变差（p ≈ 0.0002），所有场景的结束 git 调用 +1 全部判为变差，没有任何一项被误判为变好，记录摘要相同。
