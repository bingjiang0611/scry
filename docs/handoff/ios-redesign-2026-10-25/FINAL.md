## 已知问题（不再处理）

1. **AX3 下发送后空白、已完成会话打开空白。** 只在辅助大字号出现。测量显示视口落在 LazyVStack 估算高度里没有真实行的区域，offset 本身合法。试过按高度 `scrollTo`、`scrollPosition(id:)`（会挂死）、iOS 18 边缘锚点，都没解决；拆行修好了其他场景，没修好这两个。详细数据见 reports/R6-initial.md、R6.md、R6d.md。下次可以从 iOS 18 `onScrollTargetVisibilityChange` 观测可见行入手（R6e 原第 2 部分）。
2. **iOS 17 设备**的阅读区行为与改版前相同。
3. **长回复拆分后的流式路径只有离线检查证明。** 真机流式夹具太短，没触发拆分。夹具需要写进 282KB 的 `RemoteRunStore`，不提交；补丁在 reports/R6e.md。拆分后的尾行每个分块重建一次，影响小，可以以后优化。
4. **跨块文本选择。** 长回复拆行后，文字只能在一个块内选择。
5. **设置页等系统样式按钮**仍用全局 `accent` tint，浅色文字约 3.9:1。设置页不在本次范围。
6. **环境没验证的项。** XCTest 被免费签名名额挡住，新增 UI 用例只编译、没运行；性能采集 `remote.loopback` 没有采集器，记 unavailable。catalog 有 4 项、selfTest 有 3 项失败，在改版前就存在，与本次无关。

## 需要你手动做的：VoiceOver 走查

iCTRL 推不动 VoiceOver 焦点，这一项只能人工做。打开 VoiceOver 后检查：

- [ ] 首页：「全部主机」、搜索、项目 / 动态 tab、每个会话行都能读到，运行中的会话会读「任务进行中」。
- [ ] 会话页头部按顺序读：返回 → 标题 → 总览 → 更多。
- [ ] 需要你决定：标题 → 类型徽标 → 问题 → 各选项（选中的读「已选」）→ 取消请求 → 提交。
- [ ] 总览：会话 ID 的「复制」按钮能读到；用量读「Mac 未提供」。
- [ ] Composer：附件、权限、模型按钮、发送都有中文标签。
- [ ] 运行环、圆点这类装饰不单独朗读。

## 与设计稿的差异：缺的是 Mac 主机数据

下面这些在设计稿里有，iOS 上没做，因为主机没提供这些数据。按规矩不能估算或显示 0。要补齐，需要扩展主机协议。

| 设计稿里的内容 | 缺的主机数据 |
|---|---|
| 首页「已完成」分组、未读点 | 每个会话的最后运行结果与已读状态（lastRunOutcome / unread） |
| who 行显示模型 · 强度 | 每轮实际使用的模型与推理强度 |
| 思考行的秒数 | 每段推理的时长 |
| 工具组按类别分徽标、显示时长 | 结构化的工具类别与每次调用耗时（现在只有一行自由文本） |
| 每轮页脚的文件数与 +/− 行数 | 每轮的文件 diff |
| 总览：上下文占用刻度、Token / 费用 / 时长 | 上下文窗口与占用、累计 token、费用、会话时长 |
| 总览：文件 / 时间线标签 | 每轮文件与时间线 |
| 总览：点轮次跳到正文 | 阅读区按轮次定位的接口（iOS 侧） |
