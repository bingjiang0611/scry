# R2 首页：去掉抽屉，首页 = Mac 侧栏

分支 `design/ios-redesign`，基于 R1（已核验）。先读 [SPEC.md](SPEC.md) §3、§5.1、§5.4 和设计稿 `mockups/Main.dc.html`。本批只做首页；会话页、Sheet 留给 R3/R4。

## 数据边界（先读）

iOS 拿到的会话目录是 `RunSessionRef`：`label`、`cwd`、`providerId`、`ts`、`pinnedAt`、`isActive`、`archivedAt`；运行状态来自 store 的 `liveRun(...)` 和 `openLiveQuestion(...)`。**没有** Mac 的 `lastRunOutcome`，也没有「未读」。因此本批：

- 「动态」只做两段：**需要回复**（`openLiveQuestion != nil`）和 **进行中**（有 `liveRun` 且没有待回答）。**不做「已完成」段，也不做未读圆点**，不要用 `isActive == false`、`ts` 或本机见过的结束事件去推断「完成」。是否给主机协议加字段由用户决定，不在本批。
  - 后续（2026-10-27，F1）：主机协议其实已经带 `lastRunOutcome` / `lastRunId`（`src/shared/desktop-remote.ts` 的 `RemoteSessionRef`，`remote-gateway-sanitizers.ts` 校验后透传），缺的只是 Swift 传输模型。用户决定补齐，`turnOutcome == .completed` 现在填第三段「已完成」；**未读点仍未做**，禁止推断的规则不变（`isActive == false`、`ts`、本机结束事件依然不能推断完成）。见 [reports/F1.md](reports/F1.md)。
- `isActive == true` 但本机没有 `liveRun` 的会话，不进「进行中」；在「项目」里继续用现有的「上次：运行中」文案。
- 相对时间用 `ts`。

## 要做的事

1. **删掉抽屉**：`HomeDrawer` 的内容并入首页，`HomeView` 不再有抽屉、遮罩、拖拽手势和汉堡按钮。`DrawerTab` 改成首页标签 `projects / activity`。现有逻辑全部保留并搬过来：搜索过滤、等待回答去重（同一会话只在一处出现）、置顶排序、项目分组（按 scope + cwd）、展开状态、在项目中新建、工具入口（`ToolKind` 及其不可用说明）、目录来源说明（`panelProvenance` / 读取时间）、行操作（置顶、重命名、归档、删除确认）和撤销 toast。
2. **头部**（SPEC §5.1 第 1 条）：主机 chip（胶囊、`panel2` 底、状态点颜色沿用现有连接语义），点开的菜单内容不变（主机筛选、连接 Mac、设置）；右侧设置按钮。原来的刷新按钮去掉，改为下拉刷新加头部 chip 内的小进度（刷新中把状态点换成 `ProgressView().controlSize(.mini)`）。刷新成功 toast 保留。
3. **搜索框**：38pt、圆角 10、`subtle` 底、`border3` 边，绑定现有 `model.query`；有输入时两个标签都只显示匹配项（与 Mac 侧栏一致），标签不自动切换。
4. **标签「项目 | 动态」**：SPEC §5.1 第 3 条；下划线用 `matchedGeometryEffect` + `Motion.animation(.tab, …)`。默认选「动态」；若动态为空且没在搜索，默认选「项目」。用 `@SceneStorage` 记住上次选择。
5. **动态**：两段，每段一个标签 + 通栏发丝线（SPEC 颜色）。行 = Provider 图标 16pt（`Palette.provider(id)` 着色，SF Symbol 或自绘均可，但各 Provider 要能区分）+ 单行标题 `Typography.rowTitle` + 右侧状态列（待回答徽标 / 运行环）。行高 48。无项目副标题、无数量徽标；每段最多 40 行，超出显示「另有 N 条，请搜索定位」。会话在两段之间移动用 `.animation(Motion.animation(.tab, …), value:)` 做位置动画。空时显示一句「暂无需要回复或进行中的任务，其他会话在「项目」里」。
6. **项目**：置顶段（行尾补项目名）、项目段（项目行 + 展开的会话行，缩进 18pt，行尾：待回答 / 运行环 / 「上次：运行中」/ 相对时间）、工具段（两列网格，`ToolKind`，不可用的保持禁用并显示原说明）。展开 / 收起用 `.disclosureOpen` / `.disclosureClose`，箭头同步旋转 90°。多主机聚合时项目行显示主机名（沿用现有 `aggregatesHosts` 规则）。
7. **会话行**统一成一个组件（改 `SessionRowView` 或新建），所有地方共用；按下态 `hover` 底、圆角 10；`.listRowEntrance(index:)` 只用于首屏出现的行，注意 `LazyVStack` 里行滚出再滚回会重建 `@State`，不能因此重播入场（必要时把「已播过」的 id 集合提到首页层级）。
8. **首页卡片**：「回到任务」、后台发送队列、刷新失败横幅、未核验缓存提示保留，放在标签行上方，改成 12 圆角 `panel2` 卡片，内容和行为不变。
9. **Composer 外壳**（SPEC §5.4）：改 `HomeComposer` 和 `MessageComposer` 的外观为 20 圆角外壳 + 顶部 chip 行 + 底部控件行。发送、附件、斜杠命令、错误提示、可发送条件全部不变。会话页也用 `MessageComposer`，本批改完后会话页的 Composer 会一起变，这是预期；会话页其他部分不动。
10. 本批涉及的文件里，把 R1 的旧别名（`ink`、`muted`、`canvas` …）换成新 token，把固定字号换成 `Typography` 角色。不涉及的文件不动。

## 不要做

- 不做未读点（见数据边界）；「已完成」段已由 F1 补齐。
- 不改 `RemoteRunStore`、`ExecutionTargetCoordinator`、`AppModel` 的语义。纯展示用的分组 / 过滤可以写在 View 或一个只读的小 helper 里。
- 不动会话页正文、头部、状态条，不动 Sheet。
