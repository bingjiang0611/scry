# R1 基础层：颜色、动效、字体 token

分支 `design/ios-redesign`。先读 [README.md](README.md) 的硬约束和 [SPEC.md](SPEC.md) 第 1、2、4 节。本批**不改任何布局**，目标是让后面几批都能直接用同一套 token，并让 App 跟随系统深浅色。

## 要做的事

1. **颜色 token**（`apps/ios/ScryRemote/Theme.swift`）
   - 在 `Palette` 里按 SPEC §1 新增全部语义 token（`bg`、`sidebar`、`main`、`panel`、`panel2`、`panel3`、`border`、`border2`、`border3`、`fg`、`dim`、`dim2`、`accent`、`accentSoft`、`ok`、`warn`、`bad`、`hover`、`subtle`、五个 Provider 色），每个都是深浅两套的动态色（`UIColor { traits in … }` 包成 `Color`）。
   - 旧名字暂时保留为别名，指向新 token，让现有界面整体换色但不改布局：
     `ink→fg`、`muted→dim`、`faint→dim2`、`line→border`、`blue→accent`、`green→ok`、`amber→warn`、`surface→main`、`canvas→panel2`、`message→panel2`、`glass→panel`、`noticeBg→panel2`、`noticeInk→dim`、`warnBg→warn 12%`、`warnInk→warn`、`positive→ok`、`negative→bad`。
     别名上加一行注释说明「R2–R4 迁移后删除」。
   - 加一个 Provider id → 颜色的函数（`claude / codex / qoder / opencode / pi`，未知返回 `dim2`），R2 会用。
2. **跟随系统深浅色**：删掉 `apps/ios/ScryRemote/Info.plist` 里的 `UIUserInterfaceStyle = Dark`。然后搜一遍写死的 `Color.black` / `Color.white` / `.white` / `.black` / `.preferredColorScheme`：遮罩（如抽屉的黑色 54%）可以保留；会让浅色下文字看不清的，换成 token。逐处列进报告。
3. **动效 token**（新文件 `apps/ios/ScryRemote/Motion.swift`，记得加进 pbxproj）
   - 时长 `micro 0.10 / fast 0.16 / base 0.22 / slow 0.30`，曲线 `easeOut / easeStruct / easeExit`（SPEC §4 的 `timingCurve` 参数）。
   - 一个按「是否减少动态效果」选动画的入口，例如 `Motion.animation(.disclosureOpen, reduceMotion:)`，减少动态效果时一律返回 `.linear(duration: 0.12)`；以及对应的 transition（减少动态效果时只用 `.opacity`）。至少覆盖：`press`、`select`、`tab`、`disclosureOpen`（240 struct）、`disclosureClose`（160 exit）、`rowIn`、`streamIn`（180 ease-out）、`sheet`。
   - 一个列表入场修饰器（opacity + 上移 4pt，每行延迟 16ms，最多 10 行，只在首次出现时播一次）。本批只实现，不必接入。
   - 把现有代码里的动画字面量换成 token（`grep -n "animation(\|withAnimation" apps/ios/ScryRemote/*.swift`），保留现有 reduceMotion 判断的行为。时长有变化的逐处写进报告。
4. **字体角色**（可以放在 `Theme.swift` 或新文件）：按 SPEC §2 定义角色（`reply`、`bubble`、`rowTitle`、`headerTitle`、`groupLabel`、`meta`、`mono`、`codeBlock`、`sheetTitle`），全部基于语义 text style。本批只定义，不迁移。

## 不要做

- 不改布局、间距、组件结构，不删抽屉（那是 R2）。
- 不改 `RemoteRunStore` / `AppModel` / 传输层。
- 不改 `ScryRemoteG0` target。

## 验收

- README 「验证」一节的编译、离线检查、`-selfTest`、UI 测试。
- 对比度表：用脚本算 `fg`、`dim`、`dim2`、`accent`、`ok`、`warn`、`bad` 分别在 `main`、`sidebar`、`panel2` 上的对比度，深浅两套都算，写进报告；低于 4.5:1 的标出来（浅色 `accent` 已知约 4.0，记录即可）。
- 截图：`home`、`chat`（`-uiMockData`）、`settings`、`pair` 四个路由，深色和浅色各一张，放 `reports/R1/`。深色应和现在几乎一样，只是色值变成 Mac 的中性灰和 `#5b9cff` 蓝。
- 报告写到 `reports/R1.md`，格式见 README。完成后 push 到 `design/ios-redesign`。
