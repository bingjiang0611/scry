# R4 Sheet：需要你决定、会话总览、模型 · 推理强度

分支 `design/ios-redesign`，基于 R3（已核验）。先读 [SPEC.md](SPEC.md) §5.3、§5.4 和设计稿 `mockups/Question.dc.html`、`Overview.dc.html`、`NewTask.dc.html`。

## 数据边界（先读，和设计稿不同的地方以这里为准）

- **需要你决定**：内容全部来自 `G0Transport.RunQuestionRequest`（`questionKind`、`questions[].header/question/options/multiSelect/inputMode`、`option.label/description/preview`）。设计稿里的「补充说明」输入框，只有题目本身有 `inputMode` 时才出现；不要给选择题额外加一个自由输入，主机协议不接收它。
- **会话总览**：iOS 拿不到上下文占用、上下文窗口、累计 Token、累计费用、会话时长，也没有逐轮文件 / 时间线。设计稿的占用刻度、判词行、Token / 费用 / 时长三格、「文件 / 时间线」标签**本批都不做**。总览只放能证明的东西（见下）。累计用量用**一行**「上下文占用与累计用量：Mac 未提供」说明，不画空刻度、不显示 0、不把各轮 `resultSummary` 加总（那是字符串，且可能缺轮，加总就是估算）。
- **模型 · 推理强度**：选项来自 `modelOptions`（`label`、`description`、`isDefault`、按模型的 `efforts`）与 `effortOptions`，「自动模型」「默认强度」两个现有选项保留。选择仍调用 `onModel` / `onEffort`，`modelSelectionIssue` 的显示和阻止发送规则不变。这是「下一轮的偏好」，浮层标题下写一行「用于下一轮」。

## 要做的事

1. **需要你决定 Sheet**（`RemoteQuestionSheet`，`ChatView.swift`；`ScryRemoteApp` 与 `SessionTranscriptView` 两处调用都要生效）
   - 去掉 `NavigationStack` 工具栏样式，改为 SPEC §5.3：`panel2` 底、系统抓手（`presentationDragIndicator(.visible)`）、头部 60pt「需要你决定」+ 一行「会话标题 · Provider」（调用方传入；拿不到就只显示 Provider）+ 关闭按钮（关闭 = 收起 Sheet，**不是**取消请求；现在点外部收起的行为保持）。
   - 类型徽标：`questionKind == "permission"` →「Provider 请求授权」，否则「Provider 需要输入」，`warn` 12% 底、`warn` 字、圆角 6。
   - 每题：`header`（有且问题里不含时）用 `Typography.groupLabel` `dim2`；问题 `Typography.reply` medium。
   - 选项卡片：圆角 12、最小高 52、内边距 12/14；未选 1pt `border` 边 + `main` 底；选中 1.5pt `accent` 边 + `accentSoft` 底。单选用实心圆点（160ms `.select` 缩放出现），多选用勾选方框。`description` 用 `Typography.meta` `dim2`，`preview` 用 `Typography.codeBlock`。选中切换用 `.select` 动画。
   - 文本输入题：圆角 12、1pt `border`、`main` 底，多行最少 120pt。
   - 底部固定两个 48pt 按钮：「取消请求」（`panel` 底、1pt `border2`、`fg` 字，调用原 `onCancel`）和「提交」（`accent` 底、白字、圆角 14，占 1.4 份宽）；提交中显示「提交中…」并禁用两者；未答完时「提交」禁用。错误文本在按钮上方，`bad`。
   - 逻辑（答案收集、多选拼接、`complete` 判断、提交 / 取消回调）一行不改。
2. **会话总览 Sheet**（新增 `SessionOverviewSheet.swift`）

   - `presentationDetents([.medium, .large])`、抓手可见、`main` 底；头部「总览」`Typography.sheetTitle` + 副标题「数据来自 Mac 上的会话记录」+ 关闭。
   - **会话信息**卡片（`panel2` 底、圆角 12、1pt `border3`，行高 44、行间 `border3` 发丝线）：会话 ID（`externalSessionId`，等宽、中间省略，右侧「复制」按钮，没有就「未建立会话」）、Provider、主机（scope label）、工作目录（等宽、头部省略）。只放调用方已有的值，缺就写「未提供」。
   - **用量**：一行说明（见数据边界），`Typography.meta` `dim2`。
   - **轮次**：标题「轮次」+ 发丝线；每轮一行：序号（等宽 `dim2`）+ 用户消息单行截断 + 右侧状态：进行中显示运行环；已结束且有 `resultSummary` 显示原文（单行截断）；其他留空。点一行关闭 Sheet 并滚动到该轮——如果需要改 `ConversationScrollView` 才能做到，**这一项不做**，只列表展示，写进报告。
   - 「项目文件与 Diff」按钮放在底部（次按钮样式），打开现有 `WorkspaceBrowserView`，说明文字「当前工作区相对 HEAD，不是本会话的改动」。
3. **模型 · 推理强度浮层**（`MessageComposer.modelEffortControl`）
   - 把 `Menu` 换成按钮 + `.popover(... ) { … }.presentationCompactAdaptation(.popover)`（iOS 16.4+，部署下限 iOS 17 可用），锚在按钮上，宽 300。
   - 内容：标题「模型与推理强度」+「用于下一轮」（`dim2`）；模型列表（自动模型在最前；每行名称 + `description`，`isDefault` 的标「默认」小徽标；选中打勾 `accent`；行高 ≥ 46）；分隔线；推理强度分段控件（选项 = 当前模型的 `efforts`，没有时用 `effortOptions`；最前是「默认」；滑块用 `matchedGeometryEffect` + `.tab`；选项多于 5 个时改为列表，不挤压到 44pt 以下）。没有任何强度选项时整段不显示。
   - 外观：`panel2` 底、圆角 16、1pt `border`、浮层阴影；出现用 `.select`（减少动态效果时只有淡入）。
   - 按钮本身样式不变（R2 已做），打开时加 `hover` 底。
