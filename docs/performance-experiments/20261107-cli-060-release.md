## 为什么发到 `@ali/` 而不是仓库里的 `scry-turn-recorder`

内网 registry 只接受 scoped 包名。按仓库清单直接发布被服务端拒绝：

```
npm error 403 403 Forbidden - PUT https://registry.anpm.alibaba-inc.com/scry-turn-recorder
npm error [E403] Package scope required, legal scopes: "@ali, @alife, @kaola, @yunfengdie, ..."
```

沿用 [0.2.52](20261027-cli-052-release.md) 的既有做法，发布到历史包名 `@ali/scry-turn-recorder`，仓库清单保持不变（仍是公开名 `scry-turn-recorder`）。发布产物与仓库清单只有两处差异：`package.json` 的 `name`、README 的安装行（`npm install -g @ali/scry-turn-recorder@0.2.60`）。为此在仓库 worktree 内的临时目录（`.tmp-cli-release/cli-060`）制作了这两处改名后的副本再发布；`diff -r` 只有这两个文件的两行差异，源码、`dist` 与其余文档与仓库逐文件相同。临时目录在发布后删除。

未发布到公网 npmjs：本机 npmjs token 已失效（`npm whoami` → 401 Unauthorized，`npm publish` → E404）。`scry-turn-recorder` 在公网仍未被占用（404）。
