# recorder 0.2.75 发布记录

## 内容

PR #111（`c59c5e3b`）合入六项改动，并把版本升到 `0.2.75`。前六项来自一次真实 Qoder 会话（978 行 transcript，sha256 `77cb7c83c85f3588ff79137fc80b5d6eea845012a587fb7018b0f6e3b8409e84`）暴露的证据缺陷。

1. **人工介入**：此前每轮都是 `available/exact/[]`（精确的零次介入）。现在只从「提问或拒绝请求 + 对应结果」这一对结构还原：问题正文取提问工具入参，答案取 `tool_result`，用户中断与宿主取消按 Provider 明写的 denial 字段分开记；没有观测到答案或取消时标 `partial` 并写原因。
2. **Skill 激活**：宿主激活通知（`system/subtype: informational`）与 `isMeta` 字符串 content 注入此前都不认。现在两者都算技能证据，同一次激活只记一条（按技能名最后一段归一），真实 Skill 调用仍优先，模型正文不再混入激活提示。
3. **Hook 失败**：`hook_non_blocking_error` 此前不在白名单，12 条失败运行全部丢失。现在逐次保留关联 ID、原始退出码（`-1` 保留为 `-1`，不写成超时）、耗时与错误正文；成功运行仍可合并。
4. **起始时间**：`startedAt` 改用 transcript 里真实提问行的时间，开启采集时间与 diff 基线时间各自保留；接续段用自己的 wake 起点。
5. **文件足迹**：区分 `succeeded` / `failed` / `rejected` / `unknown`；被拒的读取不算已读，同路径一次失败不抹掉另一次成功。
6. **`recover --expire-open`**：`expire-open` 从未注册进 `BOOLEAN_FLAGS`，`scry doctor` 文案推荐它、CodeLens 每 15 分钟自动调用它，此前一律以 `unknown option: --expire-open` 退出 1。现在注册该开关，并加两道门槛：静默满 30 分钟（仍在增长的一律不动），且开启轮次时记录的宿主进程链已经全部不存在（有一个在跑就不动）。收尾记录标 `estimated`/`partial` 并写明原因，照常提交入队；重复执行幂等。

口径细节见 [证据口径](../../packages/turn-recorder-cli/docs/evidence-limits.md) 与 [生命周期](../../packages/turn-recorder-cli/docs/lifecycle.md)。

## 未验证 / 限制

- 宿主进程链只在标准钩子安装形态（`sh -c` → `.scry/provider-hook.sh`）下取到宿主层；更深的包装层取不到证据，此时只有静默窗口一条证据（保守方向：不误收尾）。旧钩子脚本不带 `x-scry-client-pid` 时同样如此，需要 `scry integrations repair --yes` 更新脚本。
- PID 复用只在平台提供启动标记时排除（macOS `ps lstart`、Linux `/proc` start ticks）；标记缺失时按「仍在运行」处理，只会让轮次保持 open，不会误收尾。
- 未在真实 CodeLens 定时任务上验证 15 分钟一次的自动调用；只验证了命令本身可用与门槛行为。
- 发布后 merge 提交 `87b0b3d7` 的 [Performance run `43922710026`](https://github.com/bingjiang0611/scry/actions/runs/43922710026) `native` 车道在 compare 步骤退出 1。该车道只测 renderer 场景（markdown/short/short-heavy/paged），本次 diff 不含 renderer、native harness 或性能脚本改动；同一车道在 `f0e6cb67`、`f5143884` 上也以相同形态失败，PR #111 的 Performance Check 通过。report.md 未能取回（下载时 GitHub artifact 返回 `HTTP 503 Egress is over the account limit`），因此本次失败的数值原因未确定。
- 记录口径只影响新记录，不重写历史记录；旧记录缺 `status` / `id` / `exitCode` / `humanInterventionId` 时按 legacy 读取，不反推。
