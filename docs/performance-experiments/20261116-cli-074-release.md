# recorder 0.2.74 发布记录

## 内容

PR #108（`f0e6cb67`）合入五项改动，PR #109（`7d49dc3b`）把版本升到 `0.2.74`：

1. 收到本轮 Stop 的轮次记 `completed`，结束时间取 Stop 事件时间（`stopObservedAt` / `stopObservedAtSource`）。
2. 没有终态事件的开放轮次按证据收尾：SessionEnd；transcript 回复结束 + 身份匹配 + 30 分钟静默；或 `scry recorder recover --expire-open`。其余保持 open。
3. 健康与诊断：`health.openTurns` / `health.staleOpenTurns`，`openTurnsPending` 不再漏掉只停在 `open` 的轮次；doctor 逐条报告最后活动时间与是否仍在增长。
4. 每轮仓库扫描的便宜预筛（`diff.collection.strategy: 'unchanged'`），详见 [20261116-turn-diff-prefilter.md](20261116-turn-diff-prefilter.md)。
5. 字段预算截断 JSON 后仍是合法 JSON，并写明原始字节数。
