## 为什么发到 `@ali/` 而不是仓库里的 `scry-turn-recorder`

内网 registry 只接受 scoped 包名。直接按仓库清单发布被服务端拒绝：

```
npm error 403 403 Forbidden - PUT https://registry.anpm.alibaba-inc.com/scry-turn-recorder
npm error [E403] Package scope required, legal scopes: "@ali, @alife, @kaola, @yunfengdie, ..."
```

用户确认本轮发到历史包名 `@ali/scry-turn-recorder`，仓库清单保持不变（仍是公开名 `scry-turn-recorder`）。因此**发布产物与仓库清单有两处差异**：`package.json` 的 `name`、README 的安装行（`npm install -g @ali/scry-turn-recorder@0.2.52`）。为此在仓库 worktree 内的临时目录制作了这两处改名后的副本再发布，源码、`dist` 与文档其余部分与仓库逐文件相同（`diff -r` 只有这两个文件的两行差异）。

未发布到公网 npmjs：本机 npmjs token 已失效（`npm whoami` → 401 Unauthorized），`scry-turn-recorder` 在公网仍未被占用（404）。
