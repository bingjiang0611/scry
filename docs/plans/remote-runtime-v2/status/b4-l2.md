# B4-L2 main 侧 daemon 客户端与 supervisor

分支 `claude/remote-runtime-v2`。设计：[P3-batch4-design §13.2、§13.3](../P3-batch4-design.md)；任务书：[EXECUTION-BATCH4](../EXECUTION-BATCH4.md)。

## 做了什么

1. **`src/main/daemon-client.ts`：App 连本机 daemon**
   - 复用手机那条 lane 约定（`DesktopLanes` + `connectDesktopLane` 的 `path` 分支），读走 `bulk`/`control`、写留 `control`，不新造协议。
   - 入网：读 daemon 的 `0600` secret → 生成设备密钥与 CSR（复用 `generateDesktopDeviceIdentity`）→ 经 `enroll.sock` 换证书与 CA → 写 `<userData>/daemon-client.json`（`0600`，内容由调用方注入的加密函数封装，测试断言文件里没有明文私钥）。
   - 探活：`{ op:'daemonInfo' }`，与 App 版本不一致即 `daemon_version_mismatch`，**在写盘之前**失败，不留可用凭据。
   - 撤销或 daemon 换了 CA：探活被判 `device_not_authorized` → 删除本地凭据并以该原因上报，**不自动重新入网**；下一次变成「没有待入网 secret」，需要用户操作。
   - 损坏的凭据文件 fail closed（`daemon_local_grant_corrupt`），不覆盖、不重建。
   - `close()` 只关自己的 lane，不发 shutdown。
2. **`src/main/daemon-supervisor.ts`：探活 → 接入 → 拉起 → 等就绪**
   - 已有 daemon 直接接入，**不启动第二个**。
   - 「已启动」不等于「就绪」：等 `daemonInfo` 真答上来才算成功，超时给 `daemon_ready_timeout`。
   - 版本不一致返回 `{ status:'version-mismatch', action:'restart_daemon' }`，交给 UI 提示「重启后台服务」。
   - 拉起失败直接带出机器码原因（如 `remote_lease_owner_alive`），不在背后重试。
   - 探活抛错等同「没在运行」，重启后重新探活即可恢复（SIGKILL 场景）。
3. **daemon 侧版本握手**
   - `InnerMtlsHost` 支持 `info: { version }`，在传输授权之后、dispatch 之前回答 `{ op:'daemonInfo', version, protocol }`；带 `keepAlive` 的帧按 lane 约定保留连接。
   - 入网信封也带 `daemonVersion`，版本不一致时 App 连 CSR 都不必发完。
   - 新 op 记入 `scripts/daemon-ipc-ops.json`（`scopes: ["local"]`），矩阵与 ops 文档重新生成，守卫 12 条通过。

## 测试

`src/main/daemon-client.test.ts`（7 条，真实 unix socket + 真实 mTLS + 真实入网 socket）：

| 场景 | 断言 |
|---|---|
| 首次入网 | 返回 `enrolled: true`，凭据 `0600`、无明文私钥、secret 已消失 |
| 复用凭据 | 第二次 `enrolled: false`，只保留一个 active local grant |
| 无 secret | `daemon_enrollment_unavailable`，不凭空造 grant |
| 版本不一致 | `daemon_version_mismatch`，且没有写盘 |
| 撤销后 | `daemon_device_not_authorized`，凭据被删除，再次连接是「无 grant」而非自动重入 |
| daemon 不在 | `daemon_enrollment_unavailable` |
| 凭据损坏 | `daemon_local_grant_corrupt`，文件保持原样 |
| lane 请求 | 连上后 `control` lane 拿回 `daemonInfo`；关闭后 daemon 与 grant 都还在 |

`src/main/daemon-supervisor.test.ts`（8 条）：接入已有 daemon 不重复拉起、就绪前不报成功、超时/失败原因如实返回、版本不一致两处（接入与刚拉起）、探活抛错按未运行处理、SIGKILL 后重新拉起、`already-running` 竞态。
