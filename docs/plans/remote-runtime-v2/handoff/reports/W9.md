   - **建议**：macOS 正式固定为 `fullfsync=OFF, checkpoint_fullfsync=ON`；若坚持 `fullfsync=ON`，则需同步调整 8 ms 门限或接受仅在 `fullfsync=OFF` 下满足 8 ms。
   - 另请确认：**>16 KiB 大正文路径下**，8 ms 门禁是按「仅 SQLite 提交合计（0.98–1.02 ms）」计，还是包含一次外部正文文件+目录 fsync（11.89–12.22 ms）？
