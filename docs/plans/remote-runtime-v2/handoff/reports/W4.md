## 5. 与设计的出入

- **NFS 检测（macOS）**：Node.js 的 `fs.statfsSync()` 仅暴露数值 `type`，不暴露 macOS 的 `f_fstypename`。为遵守性能护栏（打开路径不派生同步子进程），`detectNetworkFilesystem()` 在 Linux 上直接匹配内核 `statfs` 魔数（NFS/CIFS/SMB/AFS/Ceph/9p），并保留注入口 `isNetworkFilesystem` 供测试验证文案与 fail-closed；macOS 运行时自动识别 NFS 留待原生/无阻塞方案，采取保守不阻断本地 APFS/HFS 的策略。
- **`orch_legacy_run` 提前建表**：在 V1 初始表结构中同步建立 `orch_legacy_run(ledger_run_id PK, run_id UNIQUE)`，供 W5（P4-1）增量导入直接复用，避免无谓升 schema 版本。
