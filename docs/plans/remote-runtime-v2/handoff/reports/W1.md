## 4. 失败与处理

1. **W1 #1 `SessionRename.test.tsx` 失败（代码未同步自 `main`）**：退出码 1，断言 `SCRY_RENAME_TEST_FAILED Error: long titles remain compact`。核对 `origin/main` 确认 `418d38b6`（PR #125：`fix(ui): keep session hover titles compact`）已修复该产品 UI 问题，但当前分支尚未合入。未在 W1 中擅自 cherry-pick 产品 UI 改动；转用 `npm run pack:artifact` 在 `dist/mac-arm64/Scry.app` 完成 #4/#5/#9/#13/#16 验证，未触碰 `/Applications/Scry.app`。

3. **本机 `git push` HTTPS 传输异常（环境问题）**：普通 `git push` 报 `fatal: remote helper 'https' aborted session`（exit 128），上游 Git 2.56.1 dry-run 报 exit 137。核对 `.git/hooks/` 无 `pre-push` hook 后，按 `references/git-transport.md` 经原生 `git-remote-https` 完成 dry-run、推送与 `git ls-remote` 精确 SHA 读回。
4. **W1 #14 `swift test` 缺 `XCTest`（环境问题）**：本机无 Xcode.app，仅 CommandLineTools；未重跑刷绿。
5. **W1 #8 `upgrade`/`quit-all` 与 #5 默认模式 ad-hoc 钥匙串弹窗（环境权限受限）**：终端 `AXIsProcessTrusted: false`，无法自动点击原生 `dialog.showMessageBox` 或 macOS 钥匙串弹窗。
