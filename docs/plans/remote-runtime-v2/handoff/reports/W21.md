## 失败与处理

- **采样 p95 超门限**：首版顺序执行四个外部读取，p50 52 ms / p95 81 ms。改为并行、空闲时省掉 `nice` 进程、`ps` 用 `ucomm`，两次实测 p95 42.5 / 44.9 ms。门限未改。
- **冒烟断言被搬迁带弱**：`sidebar-activity.mjs` 里对焦点的断言在搬迁后变成「焦点不在 body 上」，比原来弱。已改回精确元素（`.sb-new`），并补上「真按回车打开机器页」，见 `5b1530ac`。
- **打包失败（环境）**：`pack:artifact` 第一次失败在 `cpSync` 的 `EEXIST`，原因是我把 `node_modules/electron/dist` 做成了指向主检出的符号链接；换成真实副本后通过。第二次失败在 `codesign`：钥匙串里有两张同名「Apple Development」证书，`codesign` 报 ambiguous。本轮用 `CSC_IDENTITY_AUTO_DISCOVERY=false` 出未签名产物做布局冒烟，签名与公证留给发版流程。这条写进「未验证」。
- **打包冒烟抓到真缺口**：`scripts/desktop-remote-host-smoke/pairing.mjs` 的能力位断言没有 `hostMetrics`。补上，并新增「配对设备经真实 TLS 读取远程快照 + 无 PID/路径」断言。
- **全量 vitest 一次单点失败**：第一次跑出现 1 个失败（5606 通过 / 1 失败），未保留失败用例名；同一棵树重跑 5607 全绿。作为未定位抖动记录，不当作通过证据的一部分。

## 与设计的出入

- 进程归属：`providerRoots` 目前为空，daemon 子进程按可执行名（`ucomm`）归属，其余归「其他」。设计 §3 允许「无法归属」进「其他」，但「记住 Provider 根进程」这条还没接上，见「未验证」。
- `swapTotalBytes` 是新加的可空字段（设计 §3 只要求「已用/总量」能显示），为了交换条有分母。
