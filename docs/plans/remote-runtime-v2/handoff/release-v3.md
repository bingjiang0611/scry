# 远程运行协议 v3 发布说明

先在 iPhone 安装包含 `3d705db8` 的 v2 过渡版，再把宿主升级到 v3。过渡版继续使用 v2，并能把版本不匹配显示为更新 iPhone 上的 Scry 的提示。

1. 宿主仍是 v2 时，给已配对的 iPhone 更新至过渡版，并确认手机仍能连接。
2. 将配对宿主与参与转发的执行目标升级到 v3。过渡版手机连接 v3 时应提示更新 iPhone 上的 Scry。
3. 更新 iPhone 至 v3，验证订阅、分页、断线重连及执行目标转发。已配置执行目标的网关与目标需要使用彼此兼容的版本。

早于 `3d705db8` 的 iPhone 构件可能显示 `protocol_upgrade_client` 或 `protocol_mismatch`。在此情况下先更新手机。W19 的旧构件截图与新版真机结果见 [W19 报告](reports/W19.md)。
