## 怎么读这些文件

- 每个 `.dc.html` 都是画布的组件格式：普通 HTML 加行内样式。`{{…}}` 的值来自文件末尾 `renderVals()` 里的示例数据，`<sc-for>` 是循环，`<sc-if>` 是条件。文件要靠画布运行时才能显示，不能直接用浏览器打开，用来对照布局、间距和文案就行。
- 图上的数字都是示例。

## 视觉要点

实现时用 renderer 现有的颜色变量和组件，不要照抄这里的十六进制色值。以下几点要照着做：

- **卡片**：4 层很淡的叠层阴影（偏移 1/3/6/12px）、0.5px 的细描边、0.5px 的内高光；可以加 `corner-shape: superellipse(1.25)` 作为渐进增强。
- **圆角**：用同心圆角，内圆角 = 外圆角 − 内边距。
- **页面切换和视图切换分开**：
  - 「LLM 性能 / 成本与用量」是页面，用带下划线的标签；
  - 时间范围和「成本 / Token」只切换同一份数据的视图，用小号分段控件。
- **汇总卡**：按 2:1:1:1 排，第一张的数字大约 34px。
- **数字**：一律用等宽数字（`font-variant-numeric: tabular-nums`）。
- **分组**：成本表的 Agent 和它下面的模型行之间不画线，靠缩进和留白分组；Agent 之间只用一条细线。
- **曲线**：每日成本用平滑曲线，下面是浅色面积填充；线宽不跟着图表缩放。

布局以设计稿为准；数据、口径和行为以 [P9 设计文档](../../P9-analytics.md) 为准。
