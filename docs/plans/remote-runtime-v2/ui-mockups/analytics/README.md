# 分析页 UI 设计稿

在线版本（可以平移、缩放、点击跳转）：[Scry 分析](https://claude.ai/artifact/G69JhhGExKRtiS9xyyxEde)。这个链接目前只有维护者本人能打开，执行方读本目录的源文件即可。

| 文件 | 画板 |
|---|---|
| `canvas.json` | 画布索引：每个画板的位置和尺寸 |
| `Main.dc.html` | 「分析」页 · LLM 性能标签（默认打开） |
| `Cost.dc.html` | 「分析」页 · 成本与用量标签 |
| `Rules.dc.html` | 显示规则：没有数据就不显示 |

阅读这些文件时注意：
- `.dc.html` 是设计画布的组件格式，用的是普通 HTML 加行内样式。`{{…}}` 占位符的值来自文件末尾 `renderVals()` 里的示例数据，`<sc-for>` 是循环。
- 这些文件依赖画布运行时，不能直接在浏览器里打开。只对照布局、层级、间距和文案。
- 图里的数字都是示例数据。
- 实现时用 renderer 现有的颜色变量和组件，不要照抄这里的色值。
- 布局以设计稿为准；数据口径和行为以 [P9 设计文档](../../P9-analytics.md) 为准。
