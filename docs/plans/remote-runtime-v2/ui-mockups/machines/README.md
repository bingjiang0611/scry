# 机器管理 UI 设计稿

在线版本（可以平移、缩放、点击跳转）：[Scry 机器管理](https://claude.ai/artifact/LSPCVQDeBUC6wxYN2i1La9)。这个链接目前是私有的，只有维护者本人能打开。

本目录是设计稿源文件的副本，执行方读这里的文件就够了：

| 文件 | 画板 |
|---|---|
| `canvas.json` | 画布索引：每个画板的位置和尺寸 |
| `Main.dc.html` | 机器页总览：侧栏入口，本机、执行目标、已配对的设备三块 |
| `Detail.dc.html` | 本机展开后的明细：资源、Scry 占用表、本机服务与入站连接 |
| `States.dc.html` | 卡片的异常状态：离线、需要升级、读取失败、部分指标不可用 |
| `Settings.dc.html` | 设置里「远程」标签页改成的跳转提示 |

使用说明：
- 每个 `.dc.html` 是设计画布的组件格式，用的是普通 HTML 加行内样式。`{{…}}` 占位符的值在文件末尾 `renderVals()` 返回的示例数据里，`<sc-for>` 是循环。文件依赖画布运行时（`support.js`），所以不能直接用浏览器打开；对照布局、颜色、间距和文案即可。
- 图上的数字都是示例数据。
- 颜色沿用 Scry 现有的深色界面。实现时一律用 renderer 现有的颜色变量和组件，不要照抄这里的十六进制色值。
- 资源条的颜色阈值：70% 及以上为警示色，85% 及以上为危险色。
- 布局以设计稿为准；数据、口径、协议和行为以 [P8 设计文档](../../P8-machine-management.md) 为准。
