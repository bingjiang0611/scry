## 设计系统地基：尺度 token 与债务棘轮（2026-11-15）

范围是桌面 renderer 的全部 CSS。目标是把“风格不连续”从靠评审发现，变成由测试持续约束；本轮不改变任何可见外观。

| 决定 | 理由 | 落地 |
| --- | --- | --- |
| 字号收敛为 8 档 scale | 审计时共有 26 种字号，其中 10.5／11.5／12.5／13.5 等半像素字号与相邻档位只差 0.5px，读不出层级 | `--text-2xs` … `--text-2xl`（10／11／12／13／14／16／20／24px），旧的 `--text-supporting-size`／`--text-compact-size` 改为别名 |
| 字重收敛为 4 档 | 审计时共有 17 种数值字重（400 … 720，含 510、520、530 等相邻值） | `--weight-regular`／`medium`／`semibold`／`bold` |
| 间距落在 4px 网格 | 网格外的 5／6／7／9／10／14px 等约占间距声明的一半 | `--space-*` scale；1px 发丝线与 2px 光学补偿是唯一例外 |
| 债务只降不升 | 一次性重排全部界面无法逐一验证；但新代码不应继续增加债务 | `design-system.test.ts` 按文件比对 `design-system-baseline.json`；`npm run design:audit -- --write` 只允许写低 |

等价迁移：在 scale 上的字号与字重字面值（含 `font` 简写）由一次性脚本替换为 token。验证方式是反向替换——把 token 换回原字面值后与迁移前的 69 个 CSS 文件逐字节一致，主题文件只多出新增的 token 定义；因此计算样式不变。

初始基线：网格外或 scale 外的字号声明 272、字重 119、间距值 1329、裸颜色字面值 145。这些是后续分批偿还的起点，见 DESIGN.md「迁移路线」。

## 输入框、总览、设置与清单、分析视图与其余界面：全局清零（2026-11-15）

沿用侧栏与对话两轮的方法（删死代码并验证零差异 → 固定规则取整 → 颜色改由语义变量派生 → 逐类核对变化），依次处理剩余区域，最后对全部样式表收尾。所有字号、字重、间距、颜色与容器级按钮规则的发现归零后，守卫从“按文件只降不升”改为绝对规则：`design-system.test.ts` 对任何一条发现都失败，基线文件、`--write` 与按区域的检查一并删除。

| 区域 | 死声明 | 其他关键决定 |
| --- | --- | --- |
| 输入框 | 83 | 输入框正文是用户将要发出的消息，与对话中的用户消息同属阅读文本，保持 `--text-reading`；局部阴影改为 `--shadow-xs`／`--shadow-thumb`／`--shadow-float`／`--shadow-composer(-focus)`，取值不变；删除已无引用的 `.wc-*` |
| 总览 | 67 | 轮次分组胶囊保留 4px 水平内边距：380px 宽度下三列各 88px，取整到 8px 会截断“结构化介入”；会话总览密度契约（顶栏、各段间距、首个轮次位置、列数、截断、圆角）在 340／380／535px 两种主题下全部通过 |
| 设置与清单 | 95 | 清单工具栏 22→24px，与 Skills 标签页对齐（消除此前记录的 2px 偏差）；主题预览色块改用当前真实配色的固定 token（原先显示的是旧的蓝灰配色）；二维码底色为常量 `--qr-surface` |
| 分析视图 | 0 | 用量总额 31px 归到 `--text-2xl`，与总览主指标同档；三处浮动提示阴影统一为 `--shadow-menu`；次要标签对比度不变（深色 7.57:1、浅色 5.21:1） |

另外删除了 640 条只匹配“已不再产生的类名”的选择器（约 2700 行，含旧的执行图、分段视图、Provider 欢迎矩阵和账单卫士样式，以及两个删空的样式表）。判定条件：类名不出现在 `src` 下任何 TS／TSX 中，不是任何字符串或模板前缀的展开，也不出现在 416 个真实渲染片段里。

### 两个中途发现并修正的问题

1. **`:not()` 抬高优先级**。第三批起给容器级按钮规则加的 `:not(.btn, .icon-button, [role='tab'], .segmented > button)` 会把规则优先级抬到参数里最高的一项，例如 `.pinned-summary-card button { font: inherit }` 因此压过了组件自己的字号。全部改为 `:not(:where(...))`，规则保持原优先级，原生按钮的层叠与加排除条件前一致；审计只接受这种写法。改写脚本还曾把顶层裸 `button` 选择器（前面是换行）误当作容器规则，已在提交前恢复。
2. **整条删除了混合有效成员的 `:where()`**。清扫无引用类名时，`:where(h1, h2, h3, .card-title, …)` 与总览指标标签的 `:where(...)` 因含有无引用成员被整条删除，标题失去 `text-wrap: balance`、指标标签失去大写与字距。逐元素比对当时没有包含这些属性，因此没有报出。已只删除无效成员后恢复，比对属性随之扩展到 `letter-spacing`、`text-transform`、`text-wrap`、`font-variant-numeric`、`white-space`、`display`、`grid-template-columns` 等，复核结果为零差异；用同样的方法复核了更早两次类名清理，只有第三批那条 motion 规则（当时已恢复）。

仍未处理：z-index 分层 token、UX 文案逐面板审查、菜单（14 套）收敛、浮动 toast 模式。Electron 内的真实交互与 UI smoke 未在本地运行（容器以 root 运行）。

## PR CI 发现的两处行为回归（2026-11-15）

macOS 打包后的 smoke 在 PR 上报出两处由本次收敛引入的行为变化，均已修正：

1. **标题栏按钮失去 `no-drag`**。给容器级按钮规则统一加排除条件时，`styles-macos-window.css` 里让标题栏控件退出窗口拖拽区的规则也被加上了 `:not(:where(.btn, …))`。结果顶栏和侧面板顶栏里的 Button／IconButton 落在拖拽区内，点击会变成拖动窗口。这条规则只设置 `-webkit-app-region`，是行为而不是样式，已恢复为覆盖所有按钮。审计改为：只设置 `-webkit-app-region`、`pointer-events`、`user-select` 的容器规则不要求、也不应排除 primitive；`design-system.test.ts` 另加一条直接检查标题栏规则的测试，并用反向修改确认它会失败。静态渲染比对没有发现这个问题，因为它不带 `data-platform='macos'`，也不比对 `-webkit-app-region`。
2. **减少动态效果时按钮颜色过渡被关掉**。`styles-buttons.css` 在 `prefers-reduced-motion` 下写了 `transition: none`，而全局约定是把过渡缩短到 `--duration-reduced`、保留颜色反馈（动效 token 检查要求 `.btn` 的背景色过渡仍为 150ms）。已删除这段覆盖。
3. **Meta Prompts 详情栏失去纵向布局**。清扫无引用类名时删除 `.mp-row .mp-icon-button { margin-right: 4px; }`，前缀 `.mp-row` 残留并拼到下一条规则上，`.mp-detail { display: flex; flex-direction: column; … }` 变成了不匹配任何元素的 `.mp-row .mp-detail`。详情栏退回块级布局，正文不再在栏内滚动，页脚按钮被推到视口之外（1024×653 下底边在 1881px）。已恢复 `.mp-detail`，并以 `.mp-row > .icon-button` 补回复制按钮的 4px 右边距（按钮迁移到 IconButton 后丢失）。随后把每个样式表相对 main 新出现的选择器逐条核对，其余均为有意的迁移（标签页、`.notice-body`、去掉无效成员的 `:where()` 列表、终端录制弹窗布局），没有第二处拼接。416 个渲染片段里没有 Meta Prompts 详情页，所以逐元素比对没有覆盖到它。
4. **总览与能力弹窗的标签页键盘模型改变**。main 上侧栏、Skills 弹窗与 diff 导航的标签页已经是“只有选中项在 Tab 顺序里、方向键切换并选中”（roving tabindex，WAI-ARIA 推荐写法），总览数据标签与能力弹窗的种类标签则是两个都能 Tab 到、按 Enter 选中。Tabs 原语统一为前者，因此后两处的键盘行为有意改变：Shift+Tab 不再停在未选中的标签上，改用左右方向键。总览 smoke 原先按旧模型断言“Shift+Tab 到达轮次标签、Enter 选中”，已改为用原生方向键输入断言同样的结果（焦点与选中回到轮次标签、面板显示），并额外断言未选中标签不在 Tab 顺序里。侧栏 smoke 早已用方向键驱动同一个原语并通过。
