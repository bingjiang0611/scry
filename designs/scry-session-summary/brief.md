# Scry 会话信息：Compact 数字与 ID 层级

- 范围：右侧总览中的“会话 / sessionId / Compact”局部区块。
- 状态：用户已选择 A；生产实现、相关检查与安装完成。未自动重启，日常窗口效果待用户确认。
- 用户要求：先出设计稿；“未检测到”显示数字 `0`。
- 原始问题：用户截图中的完整 sessionId 占据大部分横向空间；Compact 的“未观测到”是长状态文案，不利于与非零次数比较。

## 预览

[index.html](index.html)，独立 HTML，无外部依赖。可切换两种结构、深浅主题、340/420 px 面板，以及 0、3、不可用三种演示状态。所有 ID 与状态都是示例，不读取真实会话。

- **A：紧凑信息带（已选定并实现）**：标题行右侧放 Compact 数字；下一行仅保留缩短的 ID、展开和复制入口。优先突出可扫读的次数，减少区块高度。
- **B：对齐字段行**：保留 sessionId、Compact 两行，右侧对齐字段值。迁移成本更小，整体高度稍大。
- 预览中的背景代表现有总览表面，不代表要在产品中再添加一层卡片。

## 数据语义

- `0`：当前已加载记录中未观测到确认完成的压缩。不是对原生会话完整历史的断言。
- 正数：当前记录中已确认完成的压缩次数；展示纯数字，不追加“次”。
- `—`：无法读取压缩证据。不得把缺失证据转成 0；此状态是设计边界演示，不声称当前组件已提供该状态。
- 统计范围通过 Compact 旁的提示入口提供，支持鼠标与键盘焦点。主视图不堆叠解释文案。
- sessionId 默认首 8 位和末 8 位；可展开完整 ID。复制按钮使用浏览器剪贴板 API，失败时明确告知，不显示假成功。
