数据口径
  • 输出速度 = 本轮主会话所有 LLM 调用的 output tokens 之和 ÷ 这些调用的耗时之和。耗时从请求发出到响应结束，含首 token 等待，不含工具执行。
  • output tokens 来自 Provider 上报的每次调用用量，可能包含思考 token；耗时为本机计时，属于估算，不是服务端生成速度。
  • 失败或停止的轮次保留计数，不进入中位数；缺少用量或耗时的轮次不补 0。
原型数据：本机 Pi 会话文件（近 7 天），不是 Scry 运行记录；“运行中”三行是样例 · 默认运行中无数据
