# Scry iOS Remote v5 · A / Codex Refined

## 选定方向

用户选择 A。保留 Codex 式无底栏、会话内容优先和底部 composer；不采用 B 的首页大输入框，也不采用 C 的三段底栏。

## 本轮用户补充

- `+` 不是装饰：应打开附件菜单，至少提供“照片图库”和“选择文件”，选择后在 composer 上方显示可删除的附件 chip。
- 工作目录和 Provider 是明显的整行按钮；工作目录 sheet 可从 Mac 已授权项目继续浏览上/下层文件夹并选择当前层级。
- 继续完整改善 UI 和 UX，而不是只调整颜色。

## 全量流程

1. 登录：品牌说明 + Sign in with Apple；DEBUG 本地入口保持隔离。
2. 配对：单一主动作“扫描配对码”，步骤、指纹确认和失败/超时状态在同一页表达。
3. 首页：连接状态置于标题下；列表按用户提供的最新参考改为“已置顶 + 项目”两段。置顶区只显示会话标题并可折叠；项目区以文件夹行分组，右侧可直接在该项目中新建任务，会话标题缩进排列。搜索时临时切换为带项目/Provider 元数据的扁平结果，避免丢失上下文。
4. 新任务：删除 `REMOTE TASK / 你想让 Mac 做什么？` 引导块，进入页面直接显示主机、工作目录、Provider 三个上下文；工作目录可在已授权项目内逐层浏览和选择，Provider 维持独立选择；离线或缺失选择时说明具体原因。
5. Composer 控制：`+` 弹出照片与文件来源；盾牌入口选择 Provider 实际支持的权限模式；Effort 入口选择默认模型实际支持的推理强度。Provider 只在上方上下文区切换，不在 Composer 重复展示。选择会进入真实远程请求，`full_access` 只能由用户显式选择，不能推断。
6. 附件：选择项显示名称、类型/大小和移除入口。生产实现必须诚实：只有已安全编码并进入请求的数据才能随任务发送，超限/不支持格式必须阻止发送并提示。
6. 会话：用户气泡使用中性浅灰；Agent 内容无卡片；真实生命周期置于 Agent 标识行；运行证据折叠为一行摘要。
7. 选择器：原生 sheet、刷新、空态和错误态；文件夹层级只允许 Mac 已授权项目本身及其 canonical descendants，禁止 `..` 或 symlink 逃逸；Provider 只列主机实际可用项。
8. 设置/设备：从首页菜单进入，展示配对但未验证可达与真正已连接的区别。
9. 错误/空态：优先局部提示，不用虚假成功 toast；离线允许查看已有内容，禁用发送与批准。

## 关键尺寸

- 页面左右边距 16–18pt；44pt 最小触控面。
- 顶栏 60–66pt；正文 15–17pt；辅助 11–13pt。
- composer 默认 52–110pt 自适应，不再常驻占用大块高度。
- 会话行约 62pt；只保留一行标题和一行项目/Provider 元数据。
- 蓝色仅用于主动作/运行中；绿色只表示已被真实证据确认的成功。

## 证据边界

- `已配对` 不等于 `主机可达`。
- `intent_recorded` 不等于任务执行；只有 Provider/ledger 的真实终态可显示完成。
- 未得到 tokens/cost 不显示零。
- 未传输成功的附件不得显示为已上传；历史缺失不得编造回复。
