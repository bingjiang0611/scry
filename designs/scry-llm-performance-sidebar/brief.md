## 布局与交互

1. 顺序：分析 → 紧凑 LLM 性能摘要 → 技能 → MCP → 会话列表。摘要约 90px 高，随侧栏保留；不新增主对话顶部条。
2. 输出中显示当前字符接收速度与首次输出等待；工具/审批期间速度显示 `—` 和原因，不用 0 伪装慢模型。完成后摘要展示最近一轮接收均速。
3. 整个摘要是一个查看入口。右侧临时详情面板展示本轮、近期历史、自动分组和可展开测量口径；Escape、关闭按钮退出，焦点回到入口。不要求配置、标签、刷新或过滤。
4. 不把字符速度叫 token 速度；可靠 canonical output 与 API timing 只在完整覆盖后展示本轮 API 吞吐。首次输出等待不是请求 TTFT。
5. 空、等待首字、工具等待、非流式不可用、历史读取失败、长数字、窄窗口和浅色主题有可渲染样本。对话与导航上下文是静态示例；只有性能详情与口径展开有交互。

## 自动采集：后续实现合同，不是本稿已实现能力

- 主动用户操作只有查看。移除手动网络标签、选择厂商/模型、刷新与筛选；模型/Provider/Profile/upstream 用运行时明确证据自动归类，缺失来源不猜。
- 复用已有原始流观察与终态测量。字符统计继续在主进程完成，不把逐 delta 事件变成独立 React 全树刷新。
- 主进程保留有界滚动桶；可见摘要至多 1 次/秒局部刷新，值未变不发送；不可见暂停视图更新，但继续必要观测。仅性能视图订阅摘要，不能使整个 Sidebar/会话列表每秒重渲染。
- 网络采集不主动请求公网 IP、不做测速请求、不读 Wi-Fi SSID。异步读取受约束的本机代理/路由线索，在运行开始或确认的网络变化时采样；跨运行至少 30 秒缓存，不在流式 delta、render 或每秒时钟中启动系统进程。已有缓存失效时不阻塞 Provider 启动；不能把过期快照冻结成最新网络事实。
- 分类依据必须保存来源和采样时间；只有可确认的配置线索才能建立稳定、去敏的环境指纹与匿名编号。系统代理开启不证明请求走代理，隧道接口也不等于某个 VPN。CLI 自身代理覆盖若无证据，标未知。
- 无法获得稳定环境证据的记录仍可按模型查看，但不得把所有未知记录合并为一种网络参与网络排名。实际 VPN 节点变化若无可信信号，不承诺区分。
- v1 手动标签作为旧备注保留来源，不迁移成自动检测结果，不与自动环境指纹混合参与网络归类。
- 测量自动终态落盘，详情仅首次打开及数据更新事件失效后读取有界缓存；隐藏时不扫描 JSONL。沿用最近 30 天/最多 1000 轮上限，列表只展示有界片段，失败/停止保留但不进成功样本中位数。
- 这些是性能预算与升级条件，尚未做真实采集或重渲染计数验证；实现时用高频 delta + 工具等待 + 隐藏视图检查，超预算先修共享订阅/聚合层，不增加逐消息 IPC 或高频系统轮询。
