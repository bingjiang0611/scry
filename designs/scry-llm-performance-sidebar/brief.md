## 实时绑定（后续实现合同）

- H：实时只能来自正在进行的会话，不能来自旧轮次、示例数据或随意拼接的多个运行。
- A1/默认：沿现有 App 结构绑定当前打开的本地会话的 active run。若打开的是历史会话，显示无运行；不擅自选择另一个后台 run。若用户之后明确要全局并行运行总览，回到该范围重设计，不偷偷加选择器。
- 以 sessionId + runId 保持所有权；切换会话、run 结束/取消或身份变化时清空旧实时曲线和数值。历史区独立标识，只用于近期对照，不回填实时区。
- 本轮均速仅来自主会话可计时文本片段；工具/审批边界断开，无法分离的内部停顿仍影响结果。字符不换算 token，不把全 run 墙钟当生成时间。
- 首次输出等待为本轮本地接受执行到首个主会话文本，含启动/排队，不是请求 TTFT。API 图为有 canonical token/API 时间的已完成记录推导，可能含 prefill/推理及 Provider 计入的子代理用量，不当实时主会话速度。
- 模型、Profile、Provider、upstream 使用明确运行时来源；多模型/身份未知记录分开，不猜厂商。不承诺实验性 Provider 能力一致。

## 性能与自动采集预算（尚未实现或实测）

- 复用现有旁路流观察、分段与终态测量；不发 LLM/公网 IP/测速请求，不切换 VPN，不读取 Wi-Fi SSID。
- Sidebar 只有静态入口，不订阅每秒指标。弹窗可见且有当前 run 时最多 1 次/秒局部更新，值未变不发送；关闭/不可见后停止图表订阅和视图时钟，必要的主进程观测继续。不得使整个 App/Sidebar/会话列表随指标重渲染。
- 曲线最多 30 个摘要点，使用项目原生 SVG，无 Chart 库、动画或滤镜；缺失/工具区间不补造。切换 run 即清除，不从转存文本恢复假实时曲线。
- 网络只异步读取受约束的本机代理/路由线索，按运行边界/确认的网络变化采样、至少 30 秒跨运行缓存，不逐 delta 查询系统。缓存过期或无可信信号时标未知，不阻塞 Provider 启动，不冻结过期配置为当前事实。
- 匿名环境指纹只基于去敏、有来源和采样时间的可确认配置；不输出代理凭据，不承诺 VPN 品牌/节点/实际流量路径。无法归类的记录不合并成一种网络。
- v1 手动备注保留来源，与自动环境分类分开。终态复用现有 JSONL ownership；失败/停止保留、不进成功中位数。详情按打开/数据更新失效读取缓存，隐藏不扫描历史；沿用近 30 天、最多 1000 轮上限。首屏样例聚焦当前可比较组；生产落地仍须保留所有模型/Provider 分组及逐轮数据的只读浏览，以及损坏/截断的部分证据提示，不删历史能力。
- 实现时检查高频 delta、多个后台 run、打开历史会话、切换/结束、隐藏窗口的刷新次数与数据归属。超出预算先修共享订阅/聚合层，不加逐消息 IPC 或高频系统轮询。
