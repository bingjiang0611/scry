## 当前设计

1. 分析 → **LLM 性能** → 技能 → MCP。侧栏仅普通单行入口，不显示实时数字/趋势，不增加选择、配置或刷新。
2. 点击像技能一样打开居中 Modal，直接见数字和图表；关闭按钮/Escape/焦点返回保留。旧单会话标题和 Sonnet/Claude 身份行已删除。
3. 标题行显示 **全部运行会话 · 5 个**，附输出/非输出数量，而非当前查看的会话名。
4. 三指标分别为 **平均接收速度、平均首次输出等待、平均会话均速**。每个指标显示自身可用数量，如 `3 / 5 可测`、`5 / 5 已测得`；不是把不可测样本补 0 后声称完整平均。
5. 主视觉为近 30 秒全局平均曲线。不因单个会话等工具而断开；只要其他会话可测就继续。全部不可测才留缺口；没有任何运行时不显示旧运行的实时值。
6. 下方历史仍按模型/Provider/Profile/upstream/环境分组做同类对照，不拿混合模型实时平均直接与某个模型的历史比较。本原型示例为 Sonnet/Claude 组；落地须保留所有分组、逐轮数据、失败/停止与部分证据提示。
7. 说明默认折叠为「数据口径」；保留短注 `配置线索 ≠ 实际路径`，不画网络快慢排名或百分比提升。

## 聚合合同（需求与实现计划分开）

- H：实时来源是全部当前运行会话，不受当前打开的会话/项目/页面影响；不是单会话，也不是速度之和。
- 范围是本 Scry 实例登记的运行集合，跨项目/Provider/模型；不声称扫描到应用外所有 CLI。远程/实验 Provider 无测量时显示覆盖缺失，不伪造能力一致。
- 每个会话只取其当前主 run；不把子代理/重复转发作为独立会话。复用现有 run registry、原始事件测量与明确身份，不新建另一套事实源。
- 采用会话等权算术平均：`平均接收速度(t) = Σ 可测运行会话的最近3秒接收速度(t) / 当时可测会话数`。同一时刻采样；不加权、求和、按模型挑一条或混入已结束/取消的 run。
- 各指标独立取有证据的样本。工具/审批/未首输出/缺少流证据的当前速度不当 0；确实观测到的 0 是有效测量。若分母为 0，结果 `—`。
- 平均首次输出等待只取当前仍运行、已收到首个主文本的会话，含启动/排队，不是请求 TTFT；尚待首输出会话只计运行数量，不用已等待时长替代终值。覆盖数量揭示待测/幸存者偏差。
- 平均会话均速是当前运行会话已可计时主文本片段的各会话均速的等权平均，不是合并字符除合并时间。工具等待的会话若已有可计时片段，可以贡献此指标，而不贡献当前接收速度。
- 每个趋势点按当时的运行集合计算；成员、模型、语言、上下文、缓存变化都会影响平均，不称模型/网络基准。开始/结束影响下一次聚合；切换当前查看会话不重置或换源。
- API 吞吐只在历史完整 canonical token/API 时间样本上推导；可能含 prefill/推理和 Provider 计入的子代理，单位 tok/s。字符/s 不转换 token/s，不称带宽或纯解码速度。

## 性能与网络预算（计划，尚未生产验证）

- 主进程复用登记的 active runs 和现有每-run 有界测量；一个全局采样时钟，存在运行时最多 1 次/秒 O(N) 读取小摘要并聚合，保留最多 30 点。无运行时停钟；不复制整个 trace、重读 transcript/JSONL 或逐 delta 做全局聚合。
- 保留轻量全局摘要环，以便点开直接看到已有近 30 秒趋势。弹窗只订阅小摘要，关闭/不可见后不推送或刷新 UI；Sidebar 仅静态入口，不让 App/会话列表被额外每秒重渲染。
- 使用原生 SVG，最多 30 点，无新 Chart 依赖、动画或滤镜。缓存只作展示，不将结束运行纳入当前数值。
- 自动网络只异步读取去敏、带来源/时间的本机配置线索；运行边界/确认的网络变化采样，至少 30 秒共享缓存。不逐会话每秒启动系统查询，不阻塞 Provider 启动，不把过期配置当当前事实。
- 不发 LLM/公网 IP/测速请求，不切 VPN、不读 Wi-Fi SSID、不输出代理凭据。代理开关不证明请求使用代理/直连，也不识别 VPN 品牌/节点；未知记录不池化为同一网络。
- 终态历史仍近 30 天/1000 轮，沿用 ownership/delete/billing 语义；v1 手动备注和自动证据不混。失败/停止保留但不进入成功中位数，缺 token/time 不补零。历史按需读取/缓存失效，不跟随实时采样扫描。
- 实现验收必须模拟多个项目/Provider 并行、部分不可测、全部等待、成员开始/结束、无运行、切换当前会话与隐藏窗口；计数/归属/IPC 和额外重渲染须实测，不能用原型证明生产性能。
