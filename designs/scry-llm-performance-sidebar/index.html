数据口径
  • 实时范围是 Scry 登记的所有正在运行会话，跨项目、Provider 与模型；不受当前打开页面或会话影响。结束/取消的运行立即退出当前集合，不从历史回填。
  • 每个会话等权：平均接收速度为当时可测会话速度之和 / 可测会话数，不是总吞吐。各指标显示自己的可用数量；工具/审批等待、缺少流证据不填 0，真正观测到的 0 可以参与。
  • 平均会话均速为所有运行会话中有可计时文本片段的会话均速的等权平均。首次输出等待只平均已收到首个文本的当前运行会话；尚未收到的不作为 0，不是请求 TTFT。
  • 每个趋势点使用当时运行集合。部分会话等工具时，其他可测会话继续贡献；只有全部不可测才断开。并发数、模型组合、语言与上下文变化也会改变平均值，不当模型或网络基准。
  • 历史按模型/Provider/Profile/上游/环境分别展示成功样本中位数，不把不同模型的全局平均当网络对照。API 吞吐为已完成样本的 canonical token/API 时间推导，不是实时主文本速度；示例 API 有效样本为 14/5。
  • 字符/s 不等于 token/s 或网速。系统代理配置不证明实际请求路径/VPN 节点；缺少网络证据的记录不合成一种网络。
