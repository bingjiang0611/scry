测量口径与来源
  • 字符/s 是客户端文本接收速度，不是 token/s 或网速。工具、审批等待不计入可测文本片段。
  • 首次输出等待包含启动、排队和本地开销，不是单次请求 TTFT。
  • API 吞吐仅在权威输出 token 与 API 时间完整覆盖时可用，不与字符速度混算。
  • 网络只来自可确认的本机配置线索。系统代理开启不证明请求走代理；代理关闭不等于直连。隧道接口不足以识别 VPN 品牌、节点或真实流量路径。
  • 模型、Profile、厂商来源不同的记录分开展示。提示词、缓存、上下文和服务端排队仍影响结果，不作网络快慢的因果结论。
  • 失败/停止不进入成功样本中位数。历史保留最近 30 天、最多 1000 轮；缺失不显示成零。
