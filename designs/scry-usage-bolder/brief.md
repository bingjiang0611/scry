# Scry 用量 · Bolder 设计稿

- 状态：needs-review，待用户确认；仅设计稿，未改 App 运行代码。
- Surface mode：Operate。目标是更快读出总成本、集中来源和趋势，而不是增加装饰。
- 入口：`index.html`。预览：`http://127.0.0.1:8766/index.html`。
- 启动：在仓库根目录运行 `python3 -m http.server 8766 --bind 127.0.0.1 --directory designs/scry-usage-bolder`。

## 方向

沿用用户截图和当前 `src/renderer/analytics-evidence.css` 的黑白灰、Qoder 金色与系统字体。没有新增品牌色、字体、图片、阴影卡片或装饰性动效。

1. 顶部把总额与成本构成并列。横向比例条代替四个低信息密度进度条，让 Codex 的 81.8% 在结构上可见。
2. 趋势图成为主画布，右侧为按已知成本排序的 Provider 清单。金额右对齐，来源与完整性分层。
3. 总额只保留名称与金额，不显示已知下界标记、非实际账单、轮数或数据说明入口；成本构成下不再单列 Qoder Credits。Provider 列表不显示 unknown 整行。
4. 底部五项 Token 指标统一基线，只保留名称和数值；不显示指标脚注、覆盖提示与底部解释，不把缺证据当作零。

## v2 · 去掉常驻说明小字

按用户反馈，移除 Provider 下方来源与完整性说明、各指标脚注、覆盖提示和重复辅助文案。Provider 占比与金额改为同行排列。“数据说明”集中保留这些证据。HTML 资源链接增加 v2 标识，避免浏览器继续显示旧稿缓存。

## v3 · 补回明细

用户指出模型明细遗漏。已在 Token 指标后补回“明细”表格，包括模型、成本（USD）、占比和 Token 四列，使用补充截图中可见的五行；保留模型 / 日期切换位置，日期没有来源数据，按钮禁用，不伪造日期分组。Provider 的 unknown 行移除“成本不可用”提示，仅保留名称和 `—`。

总览与补充明细截图不是同一份数据快照：表格五行合计 $2,491.59，不等于总览 $4,587.06。保留各截图原值，不推算缺失行，不重新编造占比；页面预览条和“数据说明”明确区分来源。HTML 资源版本更新为 v3。

## v4 · 隐藏 unknown 整行

纠正对用户要求的误读：Provider 主列表只展示有已知成本的 Codex、cc-switch、Qoder，复用现有 `known` 过滤结果；不是仅隐藏提示文字或改成破折号。同步将列表布局从四行改为三行，不留下空白占位。成本缺失证据仍保留在按需展开的数据说明中，不把缺失记为零。模型明细与其他内容保持不变。HTML 资源更新为 v4。

## v5 · 移除总额下方整行

按用户截图，删除“非实际账单 | 1,458 轮 数据说明”整行，包括说明入口、展开内容、箭头和对应样式，而不是只隐藏某几个词。总额保留已知下界标记；成本口径仅保留为该区的无障碍描述。预览条继续说明数据为截图样例、曲线为示意。Provider 列表、Token 指标与五行模型明细不变，资源版本更新为 v5。

验证：`node --check` 通过；Node vm 新旧对照证明旧稿不能通过整行删除检查，新稿没有 total-footer、details、上述三段文案，仍有三项 Provider 和五行模型明细。Chrome Relay 在 1512 × 708 下目视确认整行消失，无残留入口。

## v6 · 移除 Credits 和标记

按用户两张截图，删除成本构成下的“Qoder 4,577.12 Credits”整行，以及总额标题旁的“已知下界”标记；同时删除专用样式、空包装和不再使用的文案。总额、成本比例、三项 Provider、五项 Token 指标与五行模型明细不变。原型仍通过预览条与成本区无障碍描述区分示意数据和真实账单，不新增常驻说明。资源版本更新为 v6。

验证：两个 JS 文件通过 `node --check`。Node vm 新旧对照中旧稿失败，新稿可见文本没有 Credits、4,577.12 或已知下界，仍有三项 Provider、五项指标与五行模型明细。Chrome Relay 在 1512 × 708 下目视确认两处均移除，无残留边框或空行。

## v7 · 平滑曲线与悬停详情

- 曲线复用当前 `AnalyticsView.tsx:smoothPath` 的中点三次贝塞尔插值，不再使用直线连接。线宽 2px、各 Provider 面积填充透明度 0.13，与当前 App 样式一致；不改变示意日数据的峰值。
- 图表按指针横坐标吸附到最近日期，显示虚线、系列圆点及详情浮层；详情为日期与三项 Provider 每日成本。离开、失焦或 Esc 时收起。浮层左右边缘限制在图内。
- 支持键盘聚焦、左右方向键、Home/End 与 Esc。不会把鼠标选中的日期在点击聚焦时跳到最后一天。
- 不伪造截图中的每日覆盖条数。设计样本 Oct 9 中，Qoder 的 0 显示为 $0.00，cc-switch 的 null 显示 — / 当日无记录；null 仅为绘图连续沿基线连接，不会被当作零上报。
- 本轮只接通成本悬停。Token 切换仍按原设计禁用，没有虚构另一套 Token 日数据。数据均为明确标注的设计示例，不是实际账单。
- 资源版本为 v7.1；独立回归脚本：`node --test designs/scry-usage-bolder/draft.test.mjs`。

验证：5 个测试通过，覆盖与生产插值函数对照、日期吸附、0/null 区分、左右边界、键盘与收起，以及清理后的概览和五行模型明细。首次追加“鼠标聚焦不得覆盖日期”断言时为 4 通过 / 1 失败，定位并修复 focus 强制跳到末日问题后 5/5 通过，没有弱化断言。Chrome Relay 在 1512 × 764 下检查平滑曲线和浮层；通过指针移入图表的鼠标派发，回读 Oct 7 及对应三项数值，截图确认弹层、虚线与圆点；Esc 后回读确认弹层已收起。pointerleave、方向键和左右边界由单元测试验证，未逐项通过浏览器输入重放。

## 事实与示意的边界

- 总额、Provider 金额/比例、Credits、Token 指标与覆盖范围均沿用用户截图，不读取用户 DB、会话或真实账单。
- 没有补全截图中 Codex 被截断的 Token 数字。
- 每日曲线为人工示意数据，不是从截图精确采样；页面顶部及图表可访问名称均声明此边界。
- unknown 不在 Provider 主列表展示，不分配比例；原始缺失状态保留在原型数据中，不能据此宣称全部成本已知。
- 返回、7/30/90 天、刷新、Token 切换以及模型 / 日期切换均禁用。数据说明入口已在 v5 移除，没有伪造数据加载。
- UI 文案集中在 `copy.js`，渲染在 `draft.js`，样式在 `style.css`。零依赖，无外部资源请求。
