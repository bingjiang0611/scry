# Scry 项目管理设计稿

## 目标

- 项目与会话解耦：项目没有会话时仍保留在侧栏。
- 保持 Scry 现有视觉密度与浅/深色 token，只借鉴 Codex 的项目管理逻辑。
- 支持从项目行直接新建会话，并通过项目菜单完成置顶、编辑、Finder 定位与移除。

## 核心决策

1. **空项目不伪装成会话**：项目下显示“暂无会话”，避免把占位内容写入会话目录。
2. **两个快捷入口**：项目行 hover 出现“新建”和“更多”；选中空项目后，主区域也给出明确的新建入口。
3. **项目菜单是唯一管理入口**：新建会话置顶，其余低频项目操作放在菜单中。
4. **移除项目不删除目录或历史**：确认文案明确只从 Scry 项目列表移除；再次打开目录即可恢复。
5. **项目上下文可见**：主区域顶部显示项目名和路径，防止会话创建到错误目录。

## 原型操作

- 点击项目行切换项目。
- 点击项目行右侧 `+` 或菜单中的“在此项目新建会话”。
- 点击 `···` 打开项目菜单。
- 菜单支持置顶、编辑项目和移除项目；编辑与移除带弹层反馈。
- 点击左下角“浅色 / 深色”切换主题。
